# 🚀 Smart Task Manager

A modern cross-platform Smart Task Manager built with a real-time architecture. The project includes a Web Application, Android App, Windows Desktop App, and Chrome Extension, providing seamless task management across multiple platforms.

## ✨ Features

- 🔐 Secure Authentication
- ✅ Task CRUD Operations
- ⚡ Real-Time Updates using Supabase Realtime
- 🎨 Modern Liquid Glass UI
- 📝 HTML Canvas Annotation & Signature Support
- 🔔 Live Task Synchronization
- 📊 Dashboard Analytics
- 🏷️ Task Priority & Status Management
- 📱 Cross-Platform Experience
- 🌙 Responsive Design

## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/Mubashir0408/smart-task-manager.git
```

### Install Dependencies

```bash
npm install
```

### Run Web App

```bash
npm run dev
```

### Run Mobile App

```bash
cd mobile-app
npx react-native run-android
```

### Run Desktop App

```bash
npm run tauri dev
```
